# HSK1 lesson promotion handoff

This runbook covers the first dependency-valid unpublished HSK1 lesson only:
`hsk1-time-place-events:01-numbers`. It is a local review handoff, not a
publication instruction or HSK1 completion claim.

## Checked boundary

The deterministic artifact is
`content/review/hsk1-time-place-events-01-numbers-handoff.json`. It binds four
source artifacts and 67 exact content targets without copying the Mandarin or
Vietnamese draft payloads into the handoff:

- one lesson blueprint, 15 vocabulary drafts and four dialogue turns;
- 45 vocabulary practice items;
- one official grammar-row draft and one guided grammar item;
- two existing review batches and six required role-specific receipts;
- 15 listening audio targets plus one complete model-dialogue audio target.

All 16 audio assets, six human-review receipts, the versioned runtime package
and the promotion receipt are deliberately absent. The handoff therefore stays
learner-hidden and reports four blockers. Browser TTS is preview support only
and cannot fill an audio slot.

Reproduce the checked handoff with:

```powershell
npm run content:hsk1:promotion-handoff -- --check
npm run content:hsk1:promotion-handoff:validate
```

## Human review boundary

The two source batches are:

- `hsk1-time-place-events:01-numbers:review-v1` for vocabulary and its 45
  practice items;
- `hsk1-time-place-events:01-numbers:grammar-review-v1` for the grammar row and
  guided production item.

Use the existing `content:hsk1:review:export` command once a real assigner,
reviewer and canonical assignment time are known. Create one assignment for
each required role named in the handoff. The reviewer must decide every exact
target and the completed document must pass `content:hsk1:review:import`.
Imported files are local receipts only; they do not edit draft content, approve
the manifest, publish runtime content or grant mastery.

Do not create placeholder reviewer identities or approvals. Audio additionally
needs exact asset bytes, transcript binding, attributable native review and
rights evidence. Until every slot is real and valid, promotion must fail
closed.

## Planned import receipt

The handoff defines receipt schema v1 and target version
`hsk1-time-place-events-2026.07.1`. A future dry-run must bind the handoff hash,
target-bundle hash, before/after runtime-catalog hashes, runtime-package hash,
all review receipt hashes and all audio asset hashes. The deterministic
idempotency key is already derived from the target version and bundle digest.

No runtime package or receipt is generated by this handoff. Actual import is
allowed only after the dry-run and every human/audio gate pass against the same
source hashes.

## Dry-run result

`content:hsk1:promotion-dry-run:validate` proves that this lesson cannot be
imported alone. The current compiler treats the presence of any mapping for
`hsk1-time-place-events` as unit prerequisite closure. A one-lesson mapping
would consequently make `hsk1-daily-life` eligible and expose `daily-1` through
`daily-4`, even though the other five time/place/event lessons remain absent.

The checked dry-run therefore adds two independent safety boundaries:

- the target unit must be promoted atomically with all six authored lessons;
- no downstream unit or lesson may become eligible outside the requested
  promotion set.

Complete hash-bound test fixtures can satisfy all 6 review, 16 audio, package
and receipt slots, but fixtures never authorize import and the one-lesson run
still fails both safety boundaries. The dry-run writes neither graph nor
runtime bytes.

## Atomic unit handoff

The follow-up artifact
`content/review/hsk1-time-place-events-unit-handoff.json` binds the complete
unit instead of treating lesson 1 as independently publishable. Its exact
unit-release digest covers:

- all 6 lesson blueprints, 81 vocabulary drafts, 24 communicative dialogue
  turns and 243 vocabulary practice items;
- 25 grammar rows plus 25 grammar practice items;
- 3 topics, 3 task scenarios, 12 task-dialogue turns and 3 roleplay items;
- 15 review batches requiring 45 role-specific receipts;
- 90 audio targets: 6 lesson dialogues, 81 vocabulary listening items and
  3 task dialogues.

All evidence slots remain empty. The handoff explicitly authorizes no
downstream unit and records the missing explicit unit-release gate as a
blocker. It neither replaces the per-lesson handoff nor imports content.
