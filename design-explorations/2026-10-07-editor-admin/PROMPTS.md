# ImageGen prompts

Tool: built-in image_gen.imagegen. Use case: ui-mockup. Six independent prompts; no external visual assets supplied. Concept review only.

## A-editor

Use case: ui-mockup. Create a premium high fidelity Vietnamese web application UI design presentation image for HANZI.OS, an original Mandarin learning platform with cultivation/system fantasy aesthetic. This is a concept for non-technical content editors and administrators, not code. Large landscape 3:2 canvas, very high resolution. Exactly THREE separate complete desktop application screenshots on the board: one large full-width screenshot across top half, two smaller screenshots side by side bottom half, slim elegant gutters and short page captions outside. All screen edges visible, no devices, no perspective, no overlap. Each screenshot has a coherent persistent compact left navigation and header, generous whitespace, restrained ornamental jade seal/celestial lines at edges only, readable Vietnamese sans serif UI and elegant display headings, clear contrast, labeled line icons, comfortably large buttons. One primary action per page, visible fixed action footer on editor/detail screens. Realistic short Vietnamese copy, no lorem ipsum, no English UI except HANZI.OS and HSK. Small board subtitle 'Ý tưởng giao diện · Dữ liệu minh họa'. No technical IDs, JSON, API jargon, fake mastery charts, payment processing, or decorative noise. All counts illustrative. Render as polished actual working product screenshot rather than promotional art.
BOARD TITLE: 'A · Ngọc Lệnh / EDITOR'.
ART DIRECTION: Deep forest green #062C26 outer shell, warm ivory #F5F1DC working panels, luminous jade #40E7B3 selected navigation, thin antique gold borders, subtle mist mountain art only in compact dashboard banner. Confident luxurious fantasy academy meets calm practical publishing studio. Asymmetric clipped corners on shell, softly rounded inner form cards. Strong close kinship to HANZI.OS learner jade-and-ivory aesthetic.
Role: EDITOR / BIÊN TẬP VIỆN. Persistent navigation: 'Bàn làm việc', 'Nội dung của tôi', 'Kho học liệu', 'Bài đọc', 'Luyện đề', footer 'Trợ giúp'.
